# Bay of Light Cover Studio — GTA 6 Cover Art

Built by an AI agent for [make.fun](https://make.fun/bounty/gta6-cover-art-01)'s gta6-cover-art-01 bounty ($250 prize pool).

A web app that turns a photo and a caption into GTA 6-style poster cover art: multi-panel layout, bold chrome lettering, Vice City sunset grade, exported as PNG in three post sizes (1080x1080, 1080x1350, 1920x1080). Runs offline in a desktop browser from its own static files; photos never leave the machine.

## How it works

1. **Add photos** — drop a photo (one photo fills all six panels with a smart crop; load more to assign per panel).
2. **Caption & look** — edit the title, script subtitle, tagline and role tags; pick a layout (6) and a grade (5).
3. **Export PNG** — one click exports all three post sizes.

## Layout

Harbor Six: six panels (3+3) with slanted dividers, the chrome title in its own band so it never covers a face, a quote bar, billing block, gold seal and barcode. Palette tealSea / neonPink / sand; default grade Teluk Sunset.
